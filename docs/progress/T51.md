# T51 — Real-physics answer galaxy

The Workspace right-rail galaxy is now a real force-directed graph rendered by
the vendored **vis-network** (Apache-2.0 / MIT), not a hand-rolled SVG.

- `knowledge_fabric/health/galaxy.py` builds the payload from the tenant
  concept graph: `nodes[{id,label,deg,type,docs}]`,
  `edges[{from,to,relation,weight}]`, the `activated_ids` an answer lit
  (canonical-key hits in the retrieved passages + graph-expansion keys),
  their one-hop `halo_ids`, and a `stats` block. Read-only, DOM-free, and
  tolerant of a tenant with no graph.
- `surfaces/static/vendor/galaxy.js` (`window.KFGalaxy.mount` / `flash`) draws
  the barnesHut layout: activated nodes coral (`#F53E5A`), halo blue
  (`#0096FF`), the rest dimmed, on a navy ground. It freezes physics once
  settled, flashes the activated nodes, fits the camera to them, and opens a
  concept side-sheet (`/api/galaxy/node`) on click.
- `ask_ui__js.js` mounts KFGalaxy when the library is present and falls back to
  the inline SVG force layout otherwise (a stripped bake). The shell gained a
  `head` slot so only the galaxy pages pull the vendored scripts, same-origin
  under `/static/vendor/`; the showcase build copies them to `/vendor/`.

Nothing is fetched from a CDN. Credited in `ci/licence_manifest.json`,
`THIRD_PARTY_NOTICES.md` and `docs/CONCEPTS.md`.
