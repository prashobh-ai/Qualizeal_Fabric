# T37 — Live GitHub connector

`knowledge_fabric/connectors/github_live.py` replaces the record replay for
production. Scope: every repository of `GITHUB_ORG` plus `GITHUB_EXTRA_REPOS`
(`owner/repo`, comma-separated); the admin allow-list (`repos`) is applied last.
Auth: `GITHUB_TOKEN` (`KF_GITHUB_TOKEN` for a fine-grained PAT).

## Per repository

| Item | Call | Stored |
|---|---|---|
| Metadata | `GET /repos/{o}/{r}` | facts: description, homepage, topics, default branch, visibility, archived, size, stars, forks, licence SPDX, created, pushed, open issues |
| Languages | `GET …/languages` | facts: bytes + share per language, `primary_language` |
| Contributors | `GET …/contributors` (paginated) | facts: login, contributions, `contributors_count` |
| Commit count | GraphQL `defaultBranchRef … history { totalCount }` | facts: `commits.total` — exact |
| Commit history | GraphQL `history(first:100, after:)` ≤ 2000 | one record per commit (≤ 300) + a rolled-up history record; citation `/commit/<sha>` |
| Pull requests | GraphQL `pullRequests` with reviews, comments, files | facts: open / closed / merged / total, mean size; one record per PR with body, each review, each comment; citation `/pull/<n>` (reviews cite the review URL) |
| Issues | GraphQL `issues` with comments | one record per issue; citation `/issues/<n>` |
| Releases, tags | REST | facts + release-note passages; citation `/releases/tag/<t>` |
| Deployments | REST deployments + latest status per environment | facts: environments, latest state, count |
| Workflows | REST workflows + latest run | facts: name, last conclusion |
| Files | `git clone --depth 1` into `<fabric root>/clones/<slug>` | README, docs, code, manifests, notebooks, images through the pipeline (`github://o/r/<path>`, citation `/blob/<branch>/<path>`) |

Records for activity use the pre-chunked passages mime
(`application/x-kf-passages+json`, T38 hook in the converter): every passage
keeps its own citation URL. Areas: `Code`, `Architecture`, `Work item`,
`Release`, `Repository`. ACL: public → `group:everyone`; private →
`group:gh:<org>` plus `user:<collaborator>`.

Rate limits are read from the response headers and persisted
(`data/github_rate_limit.json`; `rate_limit_remaining()` feeds Admin →
Sources). An exhausted limit raises `ConnectorError` naming the reset time.
The cursor is `{repo: pushed_at}` — unchanged repositories are skipped.

`sync(platform, tenant)` (used by `scripts/ingest.py --github`) reports
`skipped` with the missing variable when no token or no scope is set; it never
silently passes. After the pull it refreshes `facts.json["documents"]` (T42).

## Verification

`tests/test_t37_t40_github_analysis.py` — a fake GitHub (REST + GraphQL) and a
fake clone runner: exact `commits.total` (1,284), PR counts and mean size,
languages share, deployments, workflows, ACL, one document per PR / commit /
issue / release / file, per-passage citation URLs, the recorded rate limit,
the cursor skip on the second run, the redacted token in errors.
