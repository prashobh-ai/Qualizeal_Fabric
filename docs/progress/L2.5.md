## Files created/changed

- **`GET /api/usage`** (`surfaces/http_api.py`, new) — the caller's OWN usage,
  **self-scoped**: the subject filter is fixed to the authenticated principal,
  so an asker sees only their own activity (no curate role needed, no
  escalation). Aggregated from the telemetry spine
  (`telemetry.analytics(subject=…)`) across **today (24h) / 7 d / 30 d (all)**.
  Each window returns `questions, answered, declined, tokens_in, tokens_out,
  cost, cost_saved, cache_hit_rate, by_level`; plus the tenant budget bar
  (`cap / spent / remaining`). Declined = the clarify + gap buckets.
- `ask_ui.py::renderUsage` (rail bottom) — a Today / 7d / 30d toggle;
  questions · answered · declined tiles; the **level split** as a coloured bar
  (Look it up green · Quote it blue · Summarise it purple · Reason about it
  coral) with a legend in reader words; tokens; cost; saved-by-cache; the
  **budget bar** (money); and speech seconds as a placeholder ("— with voice").
