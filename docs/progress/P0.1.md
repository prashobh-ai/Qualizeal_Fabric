# P0.1 — Read and record

The map for every later phase of the Enterprise-Ready lift. Each row is a
frozen contract from `knowledge_fabric/contracts/interfaces.py`, the concrete
adapter that implements it today, the environment variable that selects
between local and cloud, and the invariant(s) the adapter honours.

The runtime is stdlib-only by default (ADR-0001). Every real engine is an
optional adapter chosen by env with a stdlib fallback; missing packages
degrade to the stdlib adapter rather than crashing the platform.

| Contract | Purpose | Guards |

| `IdentityProvider` | Resolves caller → `Principal` and mints signed tokens | I5, I11 |
| `ModelClient` | Provider-agnostic LLM invocation with tier + budget awareness | I4, I12 |
| `Embedder` | Text → vector; self-hosted, deterministic, versioned | I9 |

| `LexicalIndex` | BM25 retrieval with ACL pre-rank filter | I5, I6 |

| `Connector` | Read-only source-system adapter emitting canonical records | I13 |

## Adapters (`knowledge_fabric/adapters/*.py`)

| Contract | Local (default) | Cloud / alternate | Env var that selects |
|---|---|---|---|
| `ObjectStore` | `objectstore.FileObjectStore` (filesystem, hash-addressed) | `cloud.S3ObjectStore` (boto3, guarded import) | `KF_OBJECTSTORE=local\|s3` (+ `KF_S3_BUCKET`, `KF_S3_PREFIX`, `AWS_REGION`) — resolved in `cloud.build_objectstore` |
| `Queue` | `queue.SqlQueue` (SQLite `jobs` table, lease sweep) | `cloud.SqsQueue` (boto3, guarded) | `KF_QUEUE=local\|sqs` (+ `KF_SQS_URL`, `KF_SQS_DLQ_URL`, `AWS_REGION`) — `cloud.build_queue` |
| `Database` (backs several contracts) | `stores/db.Database` (SQLite, WAL, per-thread) | `cloud.PostgresNotice` (pg8000, guarded; raises `CloudNotReady` if driver missing) | `KF_DB_URL` (sqlite path or `postgres://…`) — `cloud.build_database` |
| `IdentityProvider` | `identity.LocalIdP` (HS256 JWT via stdlib `hmac`; genuine signed / expiring / audience-checked) | `identity.OIDCIdentity` (PyJWT + cryptography, guarded; fails closed with `OIDCNotReady`) | `KF_IDENTITY=local\|oidc` (+ `KF_OIDC_ISSUER`, `KF_OIDC_AUDIENCE`, `KF_OIDC_JWKS_URL`) — `identity.build_identity` |
| `IdentityProvider` (dev only) | `identity.StubIdentity` (trusts request headers) | — | Inner-dev-loop only; not selected in the demo path |
| `ModelClient` | `model.MockModelClient` (deterministic latency/tokens, near-zero cost) | `model.HostedModelClient` (OpenAI-compatible endpoint) / `model.DisabledModelClient` (proves extractive core) | `KF_MODEL_MODE=mock\|hosted\|off` (+ `KF_MODEL_BASE_URL`, `KF_MODEL_API_KEY`, `KF_MODEL_FAST`, `KF_MODEL_DEEP`, `KF_MODEL_ESCALATION`) — `model.build_model_client` |
| `Embedder` | `embedder.HashingEmbedder` (256-d, blake2b, L2-normalised, model_id `kf-hash-embed-v1`) | (planned P3.2) bge-m3 server behind same 3 methods | Direct construction in `app.Platform`; P3.2 will introduce env `KF_EMBEDDER` |
| `VectorIndex` | `vectorindex.SqlVectorIndex` (SQLite `embeddings` table + cosine, ACL pre-filter) | (planned P3.1) Postgres + pgvector via same class over `cloud.PostgresNotice` | Inherits `KF_DB_URL`; P3.3 will add trigram tier |
| `LexicalIndex` | `lexicalindex.SqlLexicalIndex` (in-Python BM25 over tenant passages) | (planned P3.1/P3.3) Postgres `tsvector` + `pg_trgm` behind same interface | Inherits `KF_DB_URL` |
| `GraphStore` | `graphstore.SqlGraphStore` over `stores.repositories.GraphRepo` | (planned) managed graph DB behind same 4 methods | Inherits `KF_DB_URL` |
| `Connector` | `connectors.files.FilesConnector`, `connectors.github.GithubConnector`, `connectors.jira.JiraConnector` (all read-only; change-detecting; tombstoning) | (planned P2.x) SharePoint, Confluence, Google Drive with ACL propagation + webhooks | `connectors.registry.build_registry(env)` — one env flag per source (e.g. `KF_JIRA_URL`, `KF_GITHUB_TOKEN`) |
| `DocumentConverter` | `converter.DoclingLite` (markdown, plain, pdf-text, csv/tsv, code, transcript, scan-ocr) | (planned P2.7) real Docling adapter for PDFs / office / OCR | Direct in `app.Platform`; P2.7 will introduce `KF_CONVERTER=docling-lite\|docling` |
| `Telemetry` | `telemetry.SqlTelemetry` (one span row per stage in SQLite `spans`) | `otel_export.to_otlp` + POST (Apache-2.0 OpenTelemetry-compatible) | `KF_OTLP_URL` for export target; P5.1 will introduce real OTel SDK adapter |
| `PolicyEngine` | `governance.policy.PolicyEngine` (atomic `try_spend`, `rate_check`, `ROLE_ACTIONS`) | Same class; cloud only changes storage backend | `KF_BUDGET_CAP_USD` — read at `Platform.__init__` |
| `EvalGate` | `evaluation.gate.EvalGate` (promotion + corruption test; invalidates answer cache per tenant) | Same class in cloud | — |

## Contract types (`knowledge_fabric/contracts/types.py`)

Dataclasses that flow across every contract:

- `Coordinate` (kind ∈ {page_paragraph, bbox, timestamp, cell, symbol_line}) and `CoordinateKind`
- `Provenance` (content_hash + source + source_version + coordinate)
- `RawItem`, `Region`, `ConvertedDocument` — the intake / convert chain
- `Passage`, `Document` — retrieval unit and its immutable origin
- `GraphNode`, `GraphEdge` — Section-11 graph
- `Candidate`, `Citation`, `Answer` (with `level`, `why`, `lang`, `cache_hit`, `cost_saved`, `tokens_in/out`, `model_name`, `complexity`, `authoritative_source`, `dataset_version`, `reasoning`), `AnswerKind`
- `Principal`, `Decision`, `PolicyResult`
- `Job`

Helpers: `new_id(prefix)`, `now_ms()`.

## Wiring point (`knowledge_fabric/app.py`)

`Platform.__init__` is the only place the concrete adapter graph is built.
Application code (ingestion, answer, surfaces, governance) never learns
which shape it runs in — it holds contract instances:

- `self.db` — `cloud.build_database(env, Database)` if `KF_DB_URL` set, else local `Database(db_path)`
- `self.objects` — `cloud.build_objectstore(env, FileObjectStore(root))`
- `self.queue` — `cloud.build_queue(env, SqlQueue(db))`
- `self.embedder`, `self.vindex`, `self.lindex`, `self.graph`, `self.telemetry`, `self.converter`
- `self.model` — `build_model_client()` reading `KF_MODEL_MODE`
- `self.idp` — `build_identity(env, KF_IDP_SECRET)` reading `KF_IDENTITY`
- `self.cache` — `answer.cache.Cache` (five layers + per-tenant invalidation)
- `self.policy` — `PolicyEngine(db)` (budget cap from `KF_BUDGET_CAP_USD`)
- `self.grounding_threshold` — `KF_GROUNDING_THRESHOLD` (default 0.50)

## Notes for later phases

- **P0.2** will add `KF_PROFILE`, `pyproject.toml` extras (`[engines]`,
  `[db]`, `[otel]`, `[providers]`, `[connectors]`, `[speech]`, `[dev]`),
  a `Makefile` and compose profiles. The env matrix above stays the
  single source of truth; profiles set groups of these, not new ones.
- **P0.3** renames tenants to Q-* and users to role slugs; the shape of
  `Principal` and every ACL check is unchanged.
- **P3.x** replaces local engines behind the same contracts, so no
  application code changes — only `Platform.__init__` and env.
- **P4.x** splits L0/L1/L2/L3 inside `answer/selector.py` and introduces
  `providers/gateway.py` behind the `ModelClient` protocol.
- **P5.x** introduces a real OpenTelemetry SDK adapter behind the
  `Telemetry` protocol; `SqlTelemetry` remains the stdlib fallback.
- **P8.x** adds Speech (ASR + VAD + TTS) as three new adapters behind a
  new `SpeechRegistry` contract; not part of Section 4 today.

Any step that would violate I1–I14 is skipped and recorded as `BLOCKED:
I<n>`. Any step that needs something this map does not specify is
recorded as `BLOCKED: <exact missing thing>`.
