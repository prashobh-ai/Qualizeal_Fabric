# T43 — Agent for everything else

`knowledge_fabric/answer/tools.py` — the governed tool set, every tool
ACL-filtered by the principal and audited: `query_facts`, `search_passages`,
`read_page`, `search_code`, `get_symbol`, `describe_table`,
`run_table_query` (SELECT only), `github_api` (read-only, allow-listed
paths), `jira_search` (live JQL), `confluence_search` (live CQL),
`calculate`, `ask_user`.

`knowledge_fabric/answer/agent.py::run(platform, principal, question, context,
*, budget_usd, max_steps=8, on_step)` — the Messages API tool-use loop on
`model_large` (purpose `agent_step`, every call ledgered): the system rules
force the source order (facts → passages → code → tables → live APIs) before
any decline, `ask_user` ends the run with a clarify, the answer is composed
from tool results only (`compose.py`) with citations from every tool that
contributed, and `why.steps` records `Checked <tool> · <n> results` for the
UI stream. The tenant budget and the per-run `budget_usd` cap the loop;
hitting a cap is reported, never hidden.

Keyless mode: `AgentUnavailableError` — the governed extractive core answers
instead and every caller (bake, MCP `ask_fabric`, the queue) says which engine
ran. A configured-but-failing provider raises loudly (T35).
