# T41 — Documents of every kind

`knowledge_fabric/adapters/converter.py` routes by mime / extension
(`classify()` → `jira | passages | table | spreadsheet | transcript | code |
notebook | scan | image | docx | office | html | text`):

| Type | Method | Output |
|---|---|---|
| Word, PDF, PowerPoint | Docling when the `engines` extra is installed (`.docx` falls back to the stdlib reader; anything else raises `ConverterUnavailableError` — never an empty document) | passages with page + bbox; tables kept whole |
| Excel, CSV | `ingestion/tables.py` — `openpyxl` (`documents` extra) or the stdlib zip/xml reader, `csv` | per sheet: header detection, typed columns, `tables/<doc>/<sheet>.sqlite` (table `t`), a row passage per row, a sheet summary passage; registered in `facts.json["tables"]` |
| Images (png, jpg, gif, webp, svg) | `ingestion/images.py` — Tesseract OCR when available, ONE `model_large` call (`image_describe`) returning `{caption, text_present, entities[], kind, diagram{components[],connections[]}, chart{type,series[],readings[]}}` | passages: OCR text, caption, structured description; `images/<doc>/<name>.json`; citation to the file. Without a provider the description is `skipped`, the file stays discoverable and citeable |
| Markdown, HTML, text | the existing converter | passages |
| Audio, video | transcript route (timestamped passages) | passages |
| Code, notebooks | T25/T38 symbol chunking | symbol passages |
| Jira issues | `connectors/jira_live.py` — REST `search` (JQL `updated >= -<interval>`), fields summary, description, status, assignee, priority, labels, sprint, comments, links | facts per project (total, by status / priority / type / assignee, sprint); one passage per field and per comment; citation `<JIRA_URL>/browse/<key>` |
| Confluence pages | `connectors/confluence.py` — REST v2 pages by space, body storage → HTML → converter; attachments through this table | passages; citation the page URL; facts per space |

Every document persists `source_kind`, `citation_url`, `acl`, `arrived_at`
(`ingestion/pipeline.py::stamp_meta`), and every passage locator carries
`citation_url` + `source_kind` so the answer layer always has a URL.

Optional dependencies are declared as the `documents` extra (openpyxl,
pytesseract, Pillow, svglib, reportlab — all permissive, in the licence
manifest) and imported behind guards.
