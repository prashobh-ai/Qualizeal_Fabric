# T49 — Quality sets

`eval/sets/`: `facts.jsonl` (the ten repository questions + 40 variants),
`tables.jsonl` (20 questions over the fixture sheet with expected values),
`images.jsonl` (10 questions over stored image descriptions), `jira.jsonl`
(10 count questions), `agent.jsonl` (15 multi-tool questions with expected
citation sets). `eval/fixture.py` builds the deterministic fabric-data they run
over (three repositories, two Jira projects, a Confluence space, a 12-row
Defects sheet, two described images, symbols and an architecture document).

`eval/quality.py --sets … --model extractive|real [--sample N]` runs the T28
golden suite for the `general code followup role gap` sets and the fixture
sets through the real Level-0 / table / image paths (`agent` needs
`--model real`; in keyless mode it is reported as skipped, never passed).
Gates: `false_answer_rate = 0`, `exact_count_accuracy = 1.0`,
`citation_rate ≥ 0.95`, `agent_success ≥ 0.85`, golden suite green. A set that
cannot run fails the gate loudly. Matching is exact for counts ("1,285" is
wrong for 1,284) and tolerant (0.5 %) only for non-integer values.

Wired as `make quality-sets` and the nightly `quality.yml`.
