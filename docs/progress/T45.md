# T45 — Ask queue

Browser (`ask_ui__js.js`): a question the engine routes to Level 2 or 3 with
no baked answer shows the extractive answer plus **Get full answer**, which
opens `https://github.com/<owner>/<repo>/issues/new?template=ask.yml&labels=ask&title=<question>&body=<json>`
(`.github/ISSUE_TEMPLATE/ask.yml`). The page polls `answers/<hash>.json` every
20 s for 5 minutes and swaps the bubble; the card shows the model and cost
from the file. The queue is per browser (`localStorage`).

`.github/workflows/ask.yml`: on issue opened / labelled `ask` (and
`workflow_dispatch` with `question` for admins); checkout `main` +
`fabric-data`; doctor (`--require anthropic`); `scripts/answer_issue.py`
runs the agent under the real model (purpose `ask_queue`), writes
`answers/<hash>.json` to `fabric-data`, records the ledger row, comments the
answer with citations, labels `answered` and closes the issue; concurrency
`ask`. A failure is commented on the issue and fails the run — never a faked
answer.

The showcase test guard allows this one outbound navigation anchor to
`github.com`; nothing is ever loaded from the network.
