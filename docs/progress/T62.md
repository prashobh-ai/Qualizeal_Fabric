# T62 — Knowledge-intelligence demo

`scripts/demo_intelligence.py` narrates the T51–T60 track as one story a
stakeholder can watch, on the model-free extractive floor (no credits,
deterministic), and doubles as a smoke gate (non-zero exit if the review gate
regresses):

1. **One answer** — the galaxy concepts it lit and their halo (T51), the
   honest provider line (T52, "extractive core", not a faked model), and the
   phase / active-idle timing (T56).
2. **The curation gate** — a manual-mode document held in review never reaches
   the asker; the curator accepts it and the same question then cites it (T53).
3. **The timeline** — the ingestion log by month (T54).
4. **Graph insights** — communities with cohesion, surprising cross-domain
   links and knowledge gaps with suggested tags (T57).
5. **Token-meter + MCP** — efficiency and provider quota (T55), and the same
   community / gap insights through the governed MCP tools (T60).

Wired into `make demo` (after fundamentals and answering, before production)
and available as `make demo-intelligence`.
