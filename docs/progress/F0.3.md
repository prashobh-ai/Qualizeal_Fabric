# F0.3 — Keys and providers (Anthropic first)
Status: DONE

## Files created/changed

- `knowledge_fabric/adapters/model.py`
  - New `AnthropicModelClient` — stdlib-only Anthropic Messages API
    client (no SDK import). Lifts a `role: "system"` message from
    `messages` into the top-level `system` field, sends the current
    Anthropic Messages API shape (`x-api-key`, `anthropic-version:
    2023-06-01`), maps `escalation` to `KF_MODEL_LARGE`
    (default `claude-opus-5`) and `fast`/`deep` to `KF_MODEL_SMALL`
    (default `claude-haiku-4-5`), and returns
    `{text, usage:{in,out,tokens,cache_read,cache_creation}, cost, model_name}`.
    F7.4 will replace this with a SDK-based `providers/gateway.py`.
  - New module-level `PROVIDER_ORDER = ("anthropic", "openai", "bedrock",
    "vllm")` — the escalation chain the answer service will use.
  - `build_model_client()` rewritten. `KF_MODEL_MODE ∈
    {anthropic, openai, bedrock, vllm, hosted, mock, off}`. Default is
    `anthropic` when `ANTHROPIC_API_KEY` is set, else `mock`. Explicit
    `anthropic` without a key falls back to mock (never silently 401s
    at runtime). `bedrock` / `vllm` return mock until their adapters
    land in F7.5, so the doctor can still run and the answer path is
    exercised.
- `.env.example` — the single reference for every env var. Covers
  profile, providers (Anthropic first-class, OpenAI empty placeholder,
  Bedrock configured but inactive, vLLM optional), per-tier model ids
  with current-generation defaults, answer-path gates, telemetry,
  identity, speech and every connector credential name. Never a real
  secret. `README` should link here.
- `scripts/doctor.py` — new `check_model_ids()` calls each configured
  provider's model-list endpoint (`GET /v1/models`) and prints which
  ids are valid, so stale defaults are caught before a demo. Runs only
  when the credential is set; reports `skipped` / `deferred` otherwise
  so CI stays offline. The check is folded into the doctor's default
  human render and its JSON output.
- `tests/test_f0_providers.py` (new) — 9 tests: default provider
  selection under three environments; `off` disables; the missing-key
  fallback; provider order; `AnthropicModelClient.complete` sends the
  correct shape and unpacks usage; the doctor's model-id check reports
  `skipped` / `ok` / `stale` correctly. Every network call is
  monkeypatched so the tests run offline and never expose a key.

## Deferred

- **Provider gateway with SDK imports** (F7.4). The Anthropic SDK is
  not imported here because F7.4's grep rule reserves SDK imports for
  `providers/`. F7.4 replaces `AnthropicModelClient` with
  `providers/anthropic_.py` behind the same three-method surface,
  adds `providers/openai_.py`, `providers/bedrock_.py`,
  `providers/vllm_.py`, and enforces the grep. This F0.3 client is
  the stdlib bridge that lets `KF_MODEL_MODE=anthropic` work today.
- **Prompt caching** — the `AnthropicModelClient` reads cache-hit
  usage fields but doesn't yet insert `cache_control` breakpoints;
  F6.3 / F7.4 introduce the stable→semi-stable→volatile layout.
