# T85 — Freshness and governance on every answer

The `as of <time>` treatment (facts only before) now rides **every** answer.
Each answer carries a small governance line so a leader sees it is governed and
a curator sees it is current without opening the card.

- `AnswerService._governance_line` derives, from the answer's lead citation:
  `source_kind` (the document's source — internal / github / jira / confluence
  …), `authority` (the authoritative source when one was determined, else
  "cited"), `freshness` (the source's `ingested_at` as an `as of …` stamp), and
  `stale` (true when the source has not refreshed within 90 days).
- The Workspace renders it under every answer; a stale source turns the
  freshness amber and flags `stale`, and `Explain` can be used to show the
  working. `engine.js` mirrors the line for the static showcase.

This is the article's "answer + data updated at" applied to documents, code,
Jira and Confluence, not just KPIs.
