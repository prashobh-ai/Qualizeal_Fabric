# T84 — Persona answer contracts

`personas.py` already set lens, depth and emphasis (T27). It now also carries a
per-persona **answer contract** (`CONTRACT` + `contract_for`): the `lead` the
direct `result` opens with, and the persona-appropriate `Explain` offers the
card presents.

- developer → How it works · Callers · Dependencies
- quality → Edge cases · Coverage gaps
- delivery → Why? · Break down · Compare
- executive → Why? · Break down
- curation → Audit trail · Show working
- operations → Audit trail · Cost & level
- general → Why? · Show working

The contract shapes the result and what `Explain` offers over the **same cited
evidence** — the citations never change, only the shape and the follow-ups.
`engine.js` mirrors `CONTRACT` verbatim so the static showcase offers the same
per-persona follow-ups.

`tests/test_answer_first.py::TestPersonaContract` — two personas asking the same
question share the lead citation and overlap on evidence while their `Explain`
offers differ.
