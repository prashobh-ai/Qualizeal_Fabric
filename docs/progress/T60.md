# T60 — MCP tools for the new capabilities

`knowledge_fabric/mcp/server.py` registers three more governed tools
(19 total), each returning `{result, citations}` and never a fabricated
answer:

- `provider_status` — which model answers now (the pinned provider, the
  open-source fallback when it is unavailable, or the extractive core) and
  whether a model is reachable. Never reports a live model when none is
  configured (T52).
- `fabric_communities` — the knowledge communities the graph clusters into,
  each with size, cohesion and a low-cohesion flag (T57).
- `knowledge_gaps` — single-source concepts and thin communities with
  suggested tags, plus surprising cross-domain connections (T57).

`ask_fabric` already carries the model label (`model_name`) and now the
`timing` block on its result payload.
