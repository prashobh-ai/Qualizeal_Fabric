# T40 — Capability detection

`knowledge_fabric/analysis/capabilities.py` scans every text file of a clone
and writes `data/capabilities.json` rows
`{repo, capability, confidence, evidence[{path,line,snippet}], attributes}`.

| Capability | Evidence | Attributes |
|---|---|---|
| `rag` | vector stores, embeddings, `retriev bm25 rank_bm25 rerank rrf mmr hybrid` + a generation call | `retrieval_techniques`, `vector_store`, `embedding_model`, `chunking` |
| `knowledge_graph` | `networkx neo4j rdflib igraph`, vis-network, three.js, force graphs, entity/edge/triple symbols | `store`, `visualised` |
| `knowledge_fabric` | name / README / docs say "knowledge fabric" | `links` to `rag` and `knowledge_graph` |
| `caching` | `lru_cache cachetools diskcache redis valkey cache_control`, prompt/KV cache, `*cache*` symbols | `kinds` ⊆ answer/embedding/retrieval/prompt_kv/http, `reusable` (cache-named or cache-decorated symbols) |
| `auth` | `login sign_in authenticate verify_token jwt oauth passlib bcrypt flask_login fastapi.security msal` | `login_symbols` |
| `dashboard_ui` | CSS classes `dashboard kpi card chart tile panel grid`, chart libraries, `dashboard*` files | `css_files`, `chart_library` |
| `api_service` | `fastapi flask django express gin spring` | `framework` |
| `agent` | tool-use loops, MCP, LangGraph, function calling | `tools` |
| `data_pipeline` | `airflow prefect dagster`, scheduled workflows | — |
| `ml_model` | `torch tensorflow sklearn xgboost transformers` with training | — |
| `enterprise_readiness` | 16-point checklist (Dockerfile, compose, k8s/terraform, CI, tests dir, tests ≥ 20, auth, logging/telemetry, env config, migrations, rate limiting, load test, setup README, licence file, releases, multi-environment deployments) | `score` 0–100, `checklist[{item,present,evidence}]` |

Confidence grows with distinct evidence files; `rag` without a generation call
and `ml_model` without training are capped at 0.5. Weak evidence
(0 < confidence < 0.6) gets ONE `capability_classify` call on `model_small`
with the snippets; the reply must be `{present, confidence, reason}` or it is
ignored (`attributes.classified` records what happened). Without a provider
the classification is `skipped (no provider)` — nothing invented.

Consumers: Curator → Repositories (pills, score bar) and Insights
(capabilities across repositories, reuse candidates), the Level-0 answers
(`do we have any RAG implementation`, `which repos cache`, `is X production
ready`), MCP `list_capabilities`.
