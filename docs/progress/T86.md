# T86 — Business SLA and path panel

The article's measurement point — *where did the time go* — made a leadership
view. Admin → **Service levels** turns time-to-answer from a trace detail into a
commitment.

## What it shows

From the one-row-per-answer telemetry (`SqlTelemetry.events`) plus the
`kf.explain.requested` signal (T81), `telemetry/sla.py::service_levels` computes,
**per persona and per data type**:

- **median and p95 time-to-answer** (from each answer span's `duration_ms`),
- **fast-path share vs agent share** — fast = a known / KPI question answered on
  the extractive or fast tier (fast by design); agent = the router reasoned
  (deep / escalation, or a decomposed reasoning answer),
- **explain-request rate** — `kf.explain.requested` over answers,
- **token cost per answer**.

A headline SLA line:

    KPI and known questions answered in <X> s (p95 <Z> s; target 1–3 s);
    exploratory questions <Y> s.

and a reading line: *known questions are fast by design; reasoning takes longer
and that is expected.*

## Wiring

- The **data type** axis is the lead citation's source kind, stamped on the
  answer span (`service._lead_source_kind`) and exposed by `events()` alongside
  the routing `tier`; `sla.py` maps it to a leader-legible label (Documents /
  Code · repos / Jira / Confluence / …). The `kf.explain.requested` signal now
  carries the reader's persona, so the explain rate breaks down per persona.
- `GET /admin/service-levels` returns the report; the Admin **Service levels**
  card renders the headline line, the fast/agent/explain/cost summary, and two
  tables (by persona, by data type). `/admin/service-levels` is baked into the
  showcase admin bucket so the static Admin shows the same panel.

Additive: no existing telemetry field, dashboard or endpoint changed — the panel
reads the spine that already exists, plus two small span attributes.

## Verification

`tests/test_sla.py` drives a spread of fast answers across two personas, a
reasoning (agent) question, and an explain request, then asserts: the headline
carries the SLA and reading lines and a fast/agent partition; both fast and
agent shares are positive; the explain rate is positive and bounded; and the
per-persona and per-data-type tables carry p50 ≤ p95 and a cost per answer.

Full `pytest` green; `ruff` clean; the panel bakes into the showcase Admin.
