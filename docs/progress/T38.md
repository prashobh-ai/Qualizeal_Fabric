# T38 — Code understanding

`knowledge_fabric/analysis/` — deterministic, stdlib-only, one model call per
changed repository.

* **Symbols** (`symbols.py`): Python via `ast` (module docstring, imports,
  classes, functions, methods with qualified name, signature, decorators,
  docstring, lines, calls, imports); JavaScript/TypeScript via a brace scanner
  (`function`, arrow assignments, `class`, `export`); Java, Go, C# via
  declaration regexes + brace matching; SQL by statement; YAML by top-level
  key; notebooks by cell. `analysis/<repo>/symbols.jsonl`; the converter
  chunks non-Python code by these records (one citeable passage per symbol).
* **Comments** (`comments.py`): every docstring, block comment ≥ 2 lines, line
  comment ≥ 8 words and every `TODO FIXME NOTE HACK` line, attached to its
  symbol; `analysis/<repo>/comments.jsonl`; citation `/blob/<branch>/<path>#L<n>`.
* **Call graph** (`callgraph.py`): `ast.Call` names resolved in-repository;
  `analysis/<repo>/callgraph.json` with `calls` edges; `most_connected`.
* **Repository card** (`cards.py`): purpose line, languages, top-level
  directories, entry points, symbol count, dependency count by category,
  capabilities, tests, CI, container, infrastructure, contributors, commits,
  PRs, deployments, releases, workflows, last push — every line a fact.
  `analysis/<repo>/card.md`, ingested as `<repo> — repository card`
  (`source_kind: analysis`, authority 65).
* **Model summary** (`summary.py`, purpose `repo_summary`, `model_large`):
  input = card + README + tree depth 3 + 30 most-connected symbols with
  docstrings + capability evidence; the reply must be the JSON
  `{purpose, architecture, components[{name,path,role}], data_flow,
  retrieval_techniques[], reuse_candidates[{symbol,path,why}], risks[],
  citations[]}` — validated (types, required keys, every path present in the
  tree, techniques from the allowed list). Invalid replies are reported in
  `data/analysis_state.json` and never stored. `architecture.md` cites a path on
  every sentence; ingested as `<repo> — architecture` (authority 65). Without a
  provider the step is `skipped (extractive)`.

`analysis.run(platform, tenant)` (from `scripts/ingest.py --analysis`) analyses
every repository in `facts.json` whose clone exists and whose `pushed_at`
changed since the last analysis.
