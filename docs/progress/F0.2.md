## Files created/changed

- `.github/workflows/showcase.yml` — new workflow, deploys on every
  push to `main` and on manual dispatch. Steps: `build_showcase.py` →
  `verify_showcase.py` (fails the build on any external URL) →
  `actions/configure-pages@v5` → `actions/upload-pages-artifact@v3`
  → `actions/deploy-pages@v4`. Permissions: `pages: write`,
  `id-token: write`, `contents: read`. Concurrency group `pages`.
- `scripts/build_showcase.py` — placeholder builder (F0.2). Writes
  `dist/showcase/index.html` (the QualiZeal product shell with a
  "showcase build pending" banner), `dist/showcase/.nojekyll`, and
  copies `surfaces/static/brand/*` verbatim to
  `dist/showcase/assets/brand/`. Uses relative asset paths
  (`./assets/...`) so the `/Qualizeal_Fabric/` base path works. F8.1
  will replace this with the real static-snapshot builder.
- `scripts/verify_showcase.py` — pre-deploy gate. Fails if any HTML
  contains an `http://` or `https://` reference, if `.nojekyll` is
  missing, or if `index.html` is missing.
- `tests/test_showcase.py` (new) — four tests: build produces the
  required files with relative asset paths and the copyright + banner;
  verifier passes a clean build; verifier fails on an external URL;
  verifier fails on missing `.nojekyll`.
- `.gitignore` — ignores `dist/` (the local showcase build target).
