# L0.3 — Question bank from the real corpus (D2)
Status: DONE

## Files created/changed

- `knowledge_fabric/evaluation/bank.py` (new) — `generate(platform,
  tenant)` builds candidate questions from each document's title subject
  (`what is <X>?`, `what does <X> cover?`), runs each through the
  governed answer path with an eval principal, and keeps only those with
  confidence ≥ 0.56 that cite **≥ 2 documents** (the same gate as the
  P1.6 suggestion filter). `expected_docs` is stored as the cited
  documents' source URIs, so a generated entry is always a valid,
  ACL-filterable suggestion referencing real documents.
- `scripts/load_qualizeal_corpus.py` — replaces the hardcoded 4-question
  bank (empty `expected_docs`) with `qbank.generate(p, "qualizeal")`, so
  `make load-corpus` produces the bank from the loaded corpus.
- `eval/demo_questions.json` (new) — six hand-curated golden demo
  questions (definition, product comparison, service scope, company
  fact, a procedure, an out-of-fabric decline) for the leadership script
  (F9.1) and the Pages build (F8.3).
- `tests/test_l0_bank.py` (new) — 6 tests: subject extraction strips
  leading codes and generic words; every generated entry references ≥ 2
  loaded documents; regeneration is idempotent; the product fabric has
  no bank until a corpus loads; the golden file has the six curated
  families.

## Done-when checks

- Every suggestion on `/` references a document that is in the fabric —
  **PASS by construction**: `expected_docs` is drawn from actual answer
  citations, and `/api/suggestions` (P1.6) filters by ACL over those

  present and accessible. Verified on the fixture corpus
