# T52 — Open-source LLM fallback, shown honestly

When the pinned provider is unavailable, the fabric answers with an
open-source composer instead of silently degrading — and says so.

- `knowledge_fabric/adapters/oss_model.py` — `OSSModelClient`: an extractive +
  light NLG composer that always works, with an optional guarded DistilBART
  summariser (transformers/torch imported inside a function, never at load).
  An entity-containment guard keeps generated text grounded in the passages.
  Token counts come from tiktoken when present, else a word×1.3 estimate.
  `provider_label()` returns `{provider, model, dot:"#0CA678", label}`.
- `adapters/model.py` — `build_model_client()` gains `oss` and `auto` modes;
  `auto` uses the pinned provider when available and falls back to
  open-source otherwise. The ceiling is unchanged (Sonnet large / Haiku
  small); the fallback is only for provider-down, never a cheaper default.
- The Workspace composer shows an honest **provider badge** (Claude /
  open-source / extractive core) from `/api/provider`, and every answer's
  Model row and token counts reflect the engine that actually ran.

The open-source stack (spacy, tiktoken, transformers) is a guarded optional
dependency; the licence gate lists it and the notices credit it.
