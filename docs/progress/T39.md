# T39 — Dependencies and licences

`knowledge_fabric/analysis/dependencies.py` parses `requirements*.txt`,
`pyproject.toml` (PEP 621 + Poetry), `Pipfile`, `package.json`, `go.mod`,
`pom.xml`, `build.gradle(.kts)`, `Gemfile`, `Cargo.toml` and `*.csproj`;
resolves licences from the PyPI JSON API (`license_expression`, then the OSI
classifier, then `license`) and the npm registry; caches them in
`data/licence_cache.json`; categorises with `analysis/licence_map.json` into
`permissive | copyleft | non_commercial | unknown`.

Row (`data/dependencies.json["owner/repo"]`):
`{name, version, ecosystem, licence, category, manifest_path, licence_source}`.
An unresolvable licence is `unknown` with the reason (`HTTP 404`,
`unsupported ecosystem`, `unreachable`) — never a guess.

Surfaces: the Curator repository card (dependency table with licence pills),
the Level-0 answer `_p_licences` ("which libraries does X use / under which
licences"), the MCP tool `get_dependencies`.
