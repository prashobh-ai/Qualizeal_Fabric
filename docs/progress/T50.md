# T50 — Demo

`make demo` runs the three narratives end to end: `scripts/demo.py`
(fundamentals), `scripts/demo_answering.py` (T24–T33) and
`scripts/demo_production.py --fixture` (this track):

1. **Provider** — the provider line from `provider_status.json` (key
   fingerprint, pinned small / large models) and the run's ledger line;
   without the key it says exactly which command proves it.
2. **Admin → Models** — 7-day consumption from the ledger (calls, tokens,
   cache read, cost, by purpose) and the price table.
3. **The ten repository questions** — Level 0 from facts, exact, as-of time,
   every answer cited (commits, contributors, merged PRs, languages,
   deployments, repository count, RAG, knowledge graph, retrieval techniques,
   production readiness).
4. **Jira** — `how many open bugs in project <X>` per project.
5. **Excel** — a sheet question answered by a SELECT with a row citation.
6. **Image** — answered from the stored description (kind, caption, model).
7. **The queue** — the multi-tool question's `answers/<hash>.json` when it has
   landed (source, model, cost), else the exact pipe that produces it.

`--fixture` uses `eval/fixture.py`; without it the demo reads the live
`fabric-data`.
