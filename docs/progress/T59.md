# T59 — Surfaces

The new capabilities reach the product surfaces, live and in the static
showcase alike (the browser engine bakes each endpoint).

- **Workspace** — the real-physics galaxy (T51) with a concept side-sheet; the
  honest provider badge (T52); the phase / active-idle bar on the card (T56).
- **Curator** — curation-mode toggles + the manual review queue (T53), the
  ingestion timeline (T54) and the knowledge-graph insights card (T57).
- **Admin → Models** — the token-meter overview chips and provider badge
  (T55/T56) alongside the existing provider card and ledger consumption.

New GET endpoints: `/api/galaxy/node`, `/api/galaxy/full`, `/api/provider`,
`/curator/timeline`, `/curator/review`, `/curator/curation-modes`; enhanced
`/curator/insights` (graph), `/admin/models` (telemetry + badge), `/api/usage`
(timing). New POST: `/curator/curation-mode`, `/curator/review-decision`.

The shell gained a `head` slot so only galaxy pages pull the vendored
scripts; `engine.js` serves the new galaxy shape, node sheets, provider and
full-fabric galaxy from the baked snapshot; `build_showcase.py` copies
`/vendor`, rewrites its path, and bakes the new endpoints per role.
