# F0.1 — Single fabric
Status: DONE

Reverts the multi-tenant expansion from P0.3. Keeps the tenant guard
mechanism (invariant I5) and the `tenant` column everywhere, but there
is exactly one product tenant: `qualizeal`.

## Files created/changed

- `knowledge_fabric/tenants/demo.py` — rewritten. `DEMO_TENANTS`
  holds only `qualizeal`. `CORPORA["qualizeal"]` merges the previous
  three vertical corpora (QA + aviation-ops + health) into one tenant;
  every document keeps its per-doc `ontology` tag so the graph
  extractor still sees the three ontology packs. `QUESTION_BANK`
  merges the eight seed questions. `GITHUB_RECORDS` and `JIRA_RECORDS`
  point at `qualizeal/kf-platform`. `DEMO_USERS` is `{qualizeal:
  _ROLE_USERS}` only. `principal_for()` gained a test-only fallback:
  for tenants outside the shipped directory it synthesises a principal
  from the role template, so isolation tests never mutate the shipped
  users dict.
- `tests/util.py::_seed_isolation_tenant` — seeds a minimal ad-hoc
  tenant (e.g. `isolation-check`) purely to exercise I5. The tenant is
  never in `DEMO_TENANTS` and never user-visible.
- `knowledge_fabric/surfaces/http_api.py` — the platform bootstrap now
  seeds `qualizeal` (was `q-quality`); `/metrics` default tenant is
  `qualizeal`; `_demo_delta` synthetic github records use
  `qualizeal/kf-platform`.
- `knowledge_fabric/surfaces/ask_ui.py` — the sample-fallback code
  chooses the extra chips when tenant is `qualizeal`.
- `knowledge_fabric/surfaces/http_api.py::/api/suggestions` — the cap
  moves from the API (was 6) to the UI (`.slice(0,6)` in `ask_ui.py`);
  keeps the ACL subset relation provable on the raw endpoint even
  when the accessible set exceeds six.
- `scripts/demo.py`, `scripts/dashboard_snapshot.py`, `Makefile`,
  `README.md`, `.github/workflows/ci.yml`, `docs/STAGE2_CONTRACT.md`
  and every test file — 26 files sed-renamed: `q-quality → qualizeal`;
  `q-airlines / q-health / q-aerotech / q-assure-claims / q-pharma /
  q-devicelab / q-bank / q-assurance / q-cruise / q-retail →
  isolation-check`; `acme → qualizeal`; `northwind → isolation`; and
  a handful of test-local variables.
- `deploy/aws/README.md` — the example `tenant_slug` in the OpenTofu
  variable file becomes `qualizeal` (docs-only; code untouched per
  the "do not touch `deploy/aws/`" rule).
