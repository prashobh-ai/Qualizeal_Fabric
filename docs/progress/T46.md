# T46 — Schedules and storage

* `.github/workflows/ingest.yml` — cron `0 */6 * * *` + manual; concurrency
  `ingest`; checkout `main` and the `fabric-data` branch
  (`python -m knowledge_fabric.fabric_data_git checkout`); doctor;
  `scripts/ingest.py --website --github --jira --confluence --files --analysis --bake`;
  ledger line + ingest line in the run summary; commit and push `fabric-data`
  `[skip ci]`; `repository_dispatch: fabric-updated`.
* `.github/workflows/showcase.yml` — on push to `main`, on `fabric-updated`,
  manual; doctor; build over `fabric-data`; verify; deploy.
* `.github/workflows/quality.yml` — nightly `eval/quality.py --sets general
  code followup role facts tables images gap --model real --sample 40`; the
  T28 gates plus `exact_count_accuracy = 1.0`; fails loudly when the harness
  is missing.
* `.github/workflows/ci.yml` — the `mcp` job runs the inspector conformance
  call in the explicit keyless mode (`KF_MODEL_MODE=extractive`) with the
  inspector pinned to the v1 CLI; without that the T35 loud-failure contract
  correctly refuses to start the server (the earlier red job).

`scripts/ingest.py` reports every step as `ran | skipped | failed` with the
reason (`GITHUB_ORG not set`, `JIRA_URL … not set`, …), refreshes the
`documents` facts, appends `data/ingest_runs.jsonl`, and exits non-zero when
any step failed.

`fabric-data` layout (`knowledge_fabric/fabric_data.py`, `KF_FABRIC_ROOT` /
`KF_DATA_ROOT`): `data/{facts.json, capabilities.json, dependencies.json,
provider_status.json, prices.json, licence_cache.json, analysis_state.json,
github_rate_limit.json, quality/, api_calls/}`, `corpus/public/**`,
`clones/<repo>/`, `analysis/<repo>/{card.md, architecture.md, symbols.jsonl,
comments.jsonl, callgraph.json}`, `tables/<doc>/<sheet>.sqlite`,
`images/<doc>/<name>.json`, `answers/<hash>.json`.
