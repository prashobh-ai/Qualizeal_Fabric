# T01 — Tooling: uv, Ruff, pytest, extras, Makefile, CI, licence manifest + notices
Status: DONE

Establishes the build-and-check spine the rest of the tasks run on: a
FastAPI/Pydantic/uvicorn runtime declaration with every heavier capability behind
an optional extra, uv for envs and lock, Ruff at line-length 100 across the whole
repository, pytest as the test runner, a four-job CI pipeline, and the licence
manifest wired to a `notices.py` generator. No product behaviour changes — the
served consoles are byte-for-byte identical to the previous build.

## What changed

- **`pyproject.toml`** — `[project]` runtime deps are only `fastapi[standard]`,
  `pydantic>=2`, `uvicorn>=0.30`; every engine/db/otel/providers/connectors/
  speech/mcp/obs group is an optional extra (section 18). `[tool.ruff]`
  line-length 100, `select = ["E","F","I","B","UP","N"]`, excludes
  `static/assets/vendor` and `dist`. `[tool.pytest.ini_options]`
  `asyncio_mode="auto"`, `testpaths=["tests"]`. Hatchling ships the
  `surfaces/assets/` data files inside the wheel (verified: 16 fragments).
- **Whole-repo Ruff pass (strict)** — `ruff format` + every lint rule now clean.
  The console CSS/JS/HTML that Ruff should never lint was moved out of Python
  string literals into real files under `knowledge_fabric/surfaces/assets/`
  (read at import by `ui_common._read_asset`); the remaining long lines in real
  Python were fixed by implicit string concatenation, small restructures and
  doc rewraps. Byte-identity of every served constant was proven by hashing
  against the merged base before and after.
- **`Makefile`** — added `install` (`uv sync --extra dev`), `lint`
  (`ruff check . && ruff format --check .`), `fmt`, `test` (`uv run pytest -q`),
  `notices`, `corpus`, `showcase`; existing operator targets kept.
- **`.github/workflows/ci.yml`** — rewritten to `lint → lite → full → mcp`
  (postgres service on `full`, Node + inspector on `mcp`); every job runs the
  licence gate and the corpus policy. `lint` also enforces `notices --check`
  and `ruff format --check`.
- **`ci/licence_manifest.json`** — added the nine newly declared distributions
  (FastAPI, Pydantic, Uvicorn as runtime; pytest, pytest-asyncio, HTTPX,
  pip-audit as tooling; LiteLLM, MCP SDK as optional-runtime), all permissive.
- **`scripts/notices.py`** (new) — generates `THIRD_PARTY_NOTICES.md` from the
  manifest, grouped by linkage; `--check` guards staleness in CI. Licence data
  stays only in the manifest and this root file — never in the API or a console.
- **`THIRD_PARTY_NOTICES.md`** (new) — generated, at the repository root.
- **`tests/unit/test_corpus_policy.py`** (new) — the CI corpus-policy hook;
  asserts synthetic fixtures never target the product fabric and that fixture
  identifiers are documentation-safe. Full web-scrape policy lands at T05.
- **`docs/AWS_READINESS.md`** — completed the earlier `CloudNotReady →
  CloudNotReadyError` rename so the readiness-doc test passes.
