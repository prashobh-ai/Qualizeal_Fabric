# T44 — Coverage baking

`knowledge_fabric/baking.py` + `scripts/bake.py`: for every new or changed
document (content hash vs `data/bake_state.json`), repository, PR set, sheet
and image, generate candidate questions — templates by kind (`what is`,
`how many`, `who`, `when`, `which`, `where`) plus ONE `question_gen` call per
document on `model_small` (≤ 12 questions, validated) — answer them with the
agent (the governed service in keyless mode), keep those with citations, and
bake them to `answers/<hash>.json` (`hash = sha256(norm(question))[:16]`, the
same `norm` as `build_showcase.py` and `engine.js`).

The Pages engine serves baked answers first, then in-browser retrieval and
facts, then the queue (T45). Failures land in `data/bake_failures.json`;
Curator → Recommendations lists the documents whose generated questions
failed so a curator can fix the source.

Run summary: `Bake: n documents · baked · unchanged · questions (m from the
model) · answers · failed · answerer` in the log and `$GITHUB_STEP_SUMMARY`.
