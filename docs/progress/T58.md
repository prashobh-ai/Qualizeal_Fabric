# T58 — Two-step ingest outline

`graph_insights.outline(text)` extracts a structured outline from a document —
headings, entities (proper-noun tokens, sentence-opening stopwords excluded)
and source-traceable claims (each with a `source_hint`) — so ingestion can
analyse to an outline first and then generate a summary constrained to it,
with claims that trace back to their source.

The concept (analyse → structured outline → constrained summary with
source-traceable claims) is reimplemented from the GPL-licensed *llm_wiki* —
no code copied, not a dependency — credited in `docs/CONCEPTS.md`.
