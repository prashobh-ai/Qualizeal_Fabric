# T56 — Phase / active-idle timing

`knowledge_fabric/telemetry/timing.py` — `PhaseTimer`: a dependency-free
stopwatch (perf_counter only) a request builds as it runs. It records each
phase (`retrieve`, `summarise`, `agent_steps`, `translate`, `image`), the
total **active** time (model + tool work) and, by subtraction from the wall
clock, the **idle** time spent waiting.

- `answer/service.py` wraps retrieval as an idle phase and composition /
  translation as active phases; `attach` writes the `timing` block onto the
  answer span, and the `Answer` carries it (`answer_text.to_dict()["timing"]`)
  so a browser can render it with no re-instrumentation.
- The Workspace card shows a **phase bar** (retrieve / summarise / translate)
  with the active-vs-idle split and any tool-call count.
