# T57 — Knowledge-graph insights

`knowledge_fabric/health/graph_insights.py` derives, over the tenant concept
graph:

- **Four-signal edge relevance** — direct link, source overlap, Adamic-Adar
  and type affinity, blended (0.40 / 0.25 / 0.20 / 0.15) into one weight.
- **Communities** — Louvain (networkx, BSD-3, seed=1 for determinism) with a
  cohesion score (internal / possible edges) and a low-cohesion flag.
- **Surprising connections** — high Adamic-Adar pairs across community
  boundaries with no direct link.
- **Knowledge gaps** — single-source high-degree concepts and thin
  communities, each with suggested tags.

`insights(platform, tenant)` returns `{communities, surprising, gaps}`.
`GET /curator/insights` carries it under `graph`; `GET /api/galaxy/full`
colours the whole-fabric galaxy by community. The Curator console renders a
Knowledge-graph card. networkx is a guarded optional dependency (`graph`
extra); the concepts are reimplemented from the GPL-licensed *llm_wiki* — no
code copied, not a dependency — credited in `docs/CONCEPTS.md`.
