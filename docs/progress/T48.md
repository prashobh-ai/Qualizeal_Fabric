# T48 — MCP tools

`knowledge_fabric/mcp/server.py` adds, beside `ask`, `discover`, `corpus`:
`query_facts`, `get_repository`, `list_capabilities`, `get_dependencies`,
`search_code`, `get_pull_requests`, `get_commits`, `explain_architecture`,
`run_table_query` (SELECT only), `jira_search`, `confluence_search`,
`describe_image`, and `ask_fabric` — which runs the agent on the server with
the caller's role profile (designation → persona) and the two previous
questions as context. In keyless mode `ask_fabric` answers through the
governed extractive core and says `engine: answer_service`; a configured
provider that fails raises (T35).

Every tool reads the same `fabric_views` the UI reads, so `query_facts`
matches the Curator page by construction. The inspector `tools/list`
conformance call lists all 16 tools; CI runs it in the explicit keyless mode.
