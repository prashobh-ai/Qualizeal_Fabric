# L0.2 — Purge synthetic documents from the fabric (D1)
Status: DONE

The product fabric (`qualizeal`) no longer carries any synthetic seed
documents. `tenants/demo.py::seed` seeds fabric config and budget only.
Documents enter `qualizeal` exclusively via `make load-corpus`.

## Files created/changed

- `tests/fixtures/synthetic_corpus.py` (new) — the 12 fixture documents,
  question bank, GitHub/Jira records, identifier-safety validator, and
  two loaders: `load_into(platform, tenant="test-fabric")` (full corpus
  + bank + connectors) and `load_isolation(platform, tenant)` (minimal
  two-doc corpus for I5 isolation tests). `_register_vertical_packs()`
  registers the aviation-ops and health ontology packs at load time.
- `knowledge_fabric/tenants/demo.py` — removed `CORPORA`,
  `QUESTION_BANK`, `GITHUB_RECORDS`, `JIRA_RECORDS`, `_UNSAFE`, and the
  document-seeding body of `seed`. `seed` now sets budget only;
  `validate_identifiers()` returns `[]` (no shipped corpus).
- `knowledge_fabric/ontology/packs.py` — ships only the
  `quality-assurance` pack; added `register()` so a fixture that seeds a
  non-QA domain registers its pack. This removes the aviation/health
  entity vocabulary ("Aircraft", "Medication") from the shipped package.
- `knowledge_fabric/surfaces/http_api.py` — `_demo_delta` returns None
  (real connectors pull the live API); `start_refresh_loops` uses no
  synthetic records; `/admin/users` falls back to the role template for
  any fabric outside the product directory.
- `knowledge_fabric/surfaces/ui_common.py::demo_directory` — the static
  `questions` map is empty (suggestions come from `/api/suggestions`).
- `tests/util.py` — `seeded()` loads the fixture into a **test-fabric**
  (first tenant full, the rest isolation-only); `T = "test-fabric"`.
- 14 test files — the test-side tenant renamed `qualizeal → test-fabric`;
  `test_stage2_kbeval`, `test_eval_health`, `test_stage2_ui` reference
  the fixture instead of `demo.CORPORA/QUESTION_BANK`.
- `tests/test_l0_single_fabric.py` (new) — proves `demo.seed` leaves
  `qualizeal` document- and bank-free; the fixture loads only into the
  test fabric; corpus is identifier-safe.
- `scripts/demo.py`, `scripts/dashboard_snapshot.py`,
  `.github/workflows/ci.yml` — the narrated demo, the snapshot builder
  and the CI promotion-gate step load the fixture corpus into a
  throwaway/test fabric instead of relying on `seed` to place documents.
