# T54 — Ingestion timeline

`curation.timeline(platform, tenant, year=…, source=…, mode=…)` aggregates the
`curation_log` into a per-month view for one year: twelve buckets, each
stacking the five per-action counts (`ingested`, `accepted`, `rejected`,
`deleted`, `auto_kept`), the matching drill-down rows (oldest first), and the
list of years present. Optional `source` / `mode` filters narrow both.

- `GET /curator/timeline?year=&source=&mode=` returns
  `{year, months, rows, years}`, defaulting to the latest year with data.
- The Curator console renders it as a stacked bar per month with a year
  selector and a legend.
