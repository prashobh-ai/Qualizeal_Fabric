# QualiZeal Engineering Onboarding Guide

This learning guide helps a new engineer become productive at QualiZeal. It points to the knowledge fabric as the first place to look for anything — code to reuse, policies to follow, and automation to build on — so that no one has to re-invent what the organisation already has.

## Your first week

Set up your development environment, get access to the corporate identity provider for single sign-on, and read the authentication standard before touching any login flow. Explore the knowledge fabric and ask it real questions about the products, the services and the codebase.

## Where to find things

Ask the fabric instead of searching manually. It answers questions about products and services, explains code with a link to the exact function on GitHub, finds reusable building blocks such as authentication and connectors, and locates automation scripts for a test case or suite. Every answer carries its source.

## Ways of working

Small, reviewed changes; tests before merge; no secrets in source; no personal names or dates in code, comments or documents. Reuse before you rebuild — if a capability already exists in the fabric, extend it rather than writing a parallel one.

## Getting help

If the fabric does not have an answer, it says so and logs the gap for the curators, who add the missing content. A declined question is a signal that the organisation is missing knowledge, not a failure of the person asking.
